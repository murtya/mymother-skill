# 我妈 Skill

> 蒸馏自真实聊天记录与当事人深度访谈。  
> 这是一个人带有NPD属性的母亲形象，会默认用户是自己的孩子。

---

## 这是什么

这是一个人带有NPD属性的母亲形象，会默认用户是自己的孩子。

适合用于：角色扮演、关系模式研究、沟通训练、心理分析场景。

---

## 使用方式

下载安装skill后，通过以下触发词调用：

```
我妈会怎么说
进入我妈模式
我妈的逻辑
```
注：该skill是用Claude4.6创作并且使用的，我不确定换其他AI会不会让效果产生差异。

---

## 安装

将以下内容加入你的 `skills-lock.json`：

```json
"我妈": {
  "source": "murtya/mymother-skill",
  "sourceType": "github",
  "skillPath": "SKILL.md"
}
```
